# TATABOX 代码风格指南

> 本文档**从现有代码实测反推**得出，不是凭空拟定的规则。
> 每条约定都标注了真实分布数据（样本：120 个业务 JS 文件，不含 `js/vendor/`）。
> 与本文档冲突的历史代码不要求一次性重写；**新代码请遵循本文档**，改到旧文件时顺手对齐即可。

---

## 0. 为什么需要这份文档

本仓库**已有 ESLint**（`npm run lint:code`，CI 强制执行），但没有 Prettier / `.editorconfig`，格式与命名细节仍靠约定维持。ESLint 只能兜住基础语法与部分易错模式，结构与视觉一致性仍需 review。

本文档补上这个缺口。**约定强度用「必须 / 应该 / 可以」三级标注**，与 Git 官方文档一致：

| 级别 | 含义 |
|---|---|
| **必须** | 违反会被 CI 拦下，或会静默导致故障 |
| **应该** | 违反不报错，但 review 会被要求改 |
| **可以** | 个人偏好，团队不强求统一 |

## 1. 通用

### 1.1 文件编码与行尾（必须）

- **UTF-8 无BOM**
- **LF**（`\n`）行尾 —— 实测全仓库为 LF
- 文件末尾保留一个换行

> ⚠️ 用 Python 脚本批量改写文件时，`open(p,'w')` 会把 LF 变成 CRLF，导致 diff 膨胀到数千行假改动。
> 写入后务必校正：
> ```python
> data = open(p,'rb').read()
> open(p,'wb').write(data.replace(b'\r\n', b'\n'))
> ```

### 1.2 缩进（必须）

- **2 个空格**，不使用 Tab（实测 `tab = 0`）
- 续行对齐到上一行开头，或使用 2 空格缩进块
- 单条语句一行；确实过长时（约100 列）优先换行而非硬压缩

### 1.3 命名约定（必须）

| 对象 | 风格 | 示例 |
|---|---|---|
| 变量、函数、参数 | `camelCase` | `userProfile`、`renderScore` |
| 内部/私有函数 | `camelCase` + 前导 `_` | `_moduleDir`、`_escapeHtmlAttr` |
| 全局常量 | `UPPER_SNAKE_CASE` | `SUPABASE_URL`、`ADMIN_TOKEN_TTL` |
| CSS 自定义属性 | `--kebab-case` | `--color-sage`、`--spacing-md` |
| CSS 类名 | `kebab-case` | `.bottom-tab-bar`、`.bq-btn` |
| JS 文件名 | `kebab-case` | `smart-diagnosis.js`、`boot-mask.js` |
| 测试文件 | `<被测对象>.test.js` | `design-system.test.js` |

> CSS 类名存在**双套体系**：功能页类名（`.bottom-tab-bar`、`.community-avatar`）与
> 全局组件类（`.bq-btn`、`.bq-card`、`.bq-hint`）。**新写样式一律用 `.bq-*`**，
> 详见§6.2。

### 1.4 行尾注释（应该）

注释写在语句上方，与语句对齐，不写在行尾（超长表达式除外）：

```js
// 注释
var x = 1;

// 行尾注释：仅用于极短的补充说明（约定实测量大，故不再强制禁止）
var AUTH_UPDATE_DEBOUNCE_MS = 200;   // 认证状态变更防抖时间
```

## 2. JavaScript

### 2.1 变量声明（应该）

**用 `var`，不要用 `let`/`const`** —— 这是本仓库最强的既有约定：

| 声明 | 实测次数 | 占比 |
|---|---|---|
| **`var`** | 8594 | **86%** |
| `const` | 1157 | 12% |
| `let` | 200 | 2% |

旧代码以 `var` 为主，是历史兼容遗留。新代码默认用 `const`；确实需要重新赋值时用 `let`。不必再为旧内核新写 `var`（兼容边界见 §2.6）。

### 2.2 引号（应该）

**字符串用单引号 `'...'`** —— 实测单引号 28034处 vs 双引号 10083 处（约 73% : 27%）。

例外（必须用双引号或反引号）：
- **含单引号的字符串**：`'don\'t'`
- **含 HTML 属性值的模板字符串**：`'<div class="x">'`
- 模板字符串（反引号）用于多行拼接

```js
var name = 'Alice';                    // ✅ 单引号
var msg = "it's fine";                 // ✅ 含单引号 → 双引号
var html = '<div class="row">x</div>'; // ✅ 含双引号 → 保持单引号
var tpl = `多行
字符串`;                                // ✅ 多行用反引号
```

> 注：现有代码里有大量 `var html = '<div style="...">' + x + '</div>'` 的**字符串拼接**
> （因需 DOM 注入，且 `style="..."` 内部用双引号）。这是既有写法，
> 但**不要用它写长逻辑** —— 长逻辑请用模板字符串，见 §2.7。

### 2.3 函数（应该）

- 统一用 `function` 表达式，**不使用箭头函数**（实测箭头函数仅 330 处，
  而 `function` 约 5151 处）
- 模块私有函数用前导 `_`
- IIFE 包裹模块，避免污染全局：

```js
(function () {
  'use strict';
  // ...
})();
```

### 2.4 `'use strict'`（必须）

业务 JS 文件**必须**在 IIFE 内首行声明 `'use strict';` —— 实测 93/120 文件已声明。

```js
(function () {
  'use strict';
  // ...
})();
```

少数以`<script>` 直接加载、无 IIFE 的文件可省略，但需在文件头注释说明。

### 2.5 相等比较（必须）

**一律用 `===` / `!==`，禁止 `==` / `!=`。**

实测仍有 48 处 `==`，属历史遗留，新代码不得沿用。

> 特例：与 `null` 比较判断「未定义」时，本仓库习惯写 `typeof x === 'undefined'`，
> 而非 `x == null`。

### 2.6 浏览器兼容性（必须）

站点没有构建步骤，**业务代码按现代常青浏览器（Chrome / Edge / Firefox / Safari
近两年版本）编写**，可以使用 `const`/`let`、箭头函数、模板字符串、`class` 等
ES2015+ 语法。

旧内核不运行完整应用：`js/core/legacy-probe.js` 探测失败后会跳转到
`js/core/legacy-fallback.js` 的静态降级页。因此 **ES5 限制只适用于降级链路本身**：

| 文件 | 要求 |
|---|---|
| `js/core/legacy-probe.js` | 纯 ES5，不得使用 ES2015+ 语法 |
| `js/core/legacy-fallback.js` | 纯 ES5 |
| `index.html` 首屏内联脚本 | 纯 ES5，不得含 `onclick` 等内联事件属性（CSP 禁 `unsafe-inline`） |

新增业务代码不需要考虑旧内核；若要修改降级链路，仍按 ES5 编写，并在 PR 中说明
验证方式。

### 2.7 异步与错误处理（应该）

```js
// ✅ 优先 async/await（项目已在用）
var res = await sb.from('profiles').select('*');
if (error) { showToast('加载失败'); return; }

// ✅ 逐个 await，不并发无上限
// ✅ 超时必须有：参考 supabase-client.js 的 *_TIMEOUT_MS 常量
```

**失败必须给用户可见的反馈**（`showToast` / `bq-note`），不可静默 `catch {}`。

### 2.8 XSS 防护（必须）

所有插入 DOM 的**用户数据或题库内容**必须转义：

```js
// ✅ 现有工具
escapeHtml(text)              // js/core/utils.js
_besc(text)                   // 各模块局部实现
sanitizeUrlParam(url)         // URL 参数
```

模板拼接时：
```js
html += '<div class="row">' + escapeHtml(user.name) + '</div>';  // ✅
html += '<div>' + user.name + '</div>';                          // ❌ 禁止
```

事件属性拼接必须用 `_escapeHtmlAttr`：
```js
data-id="' + _escapeHtmlAttr(item.id) + '"    // ✅
```

## 3. HTML

### 3.1 属性引号（必须）

**所有属性值必须加双引号** —— 实测 `="` 451 处，`='` 0 处。

```html
<div class="row" id="main">      <!-- ✅ -->
<div class=row id=main>          <!-- ❌ 禁止 -->
```

### 3.2 无内联事件（必须）

**禁止 `onclick`、`onchange` 等内联事件属性**（CSP 禁用 `unsafe-inline`）。
一律用事件委托或 `addEventListener`：

```html
<!-- ❌ 禁止 -->
<button onclick="handleClick()">提交</button>

<!-- ✅ 项目惯例：委托 + data 属性 -->
<button data-on='["handleClick"]'>提交</button>
```

### 3.3 品牌与文案（必须）

- 品牌名 **`TATABOX`**（全大写）；定位语分工见 `index.html` SEO 注释：
  - 「高中生物**刷题**平台」→ title / og / twitter / manifest.name
  - 「高中生物**学习**平台」→ footer / 开机遮罩 / 内页 title
- **文案不得有 AI 腔**（详见 §7）
- 页面 `<title>` 格式：`<页面名> - TATABOX`

### 3.4 无障碍（应该）

- 可交互元素必须有 `aria-label` 或可见文字
- 纯装饰元素加 `aria-hidden="true"`
- 路由切换的程序化聚焦元素用 `tabindex="-1"`（`globals.css` 已为其去掉焦点环）

## 4. CSS

### 4.1 基本风格（必须）

- **属性名全部小写**（实测 9704 处小写 / 0 处非小写）
- 2 空格缩进
- 每条声明结尾分号
- 选择器不加多余空格；后代选择器用后代空格（`.a .b`），不用`>`
  除非确实需要

### 4.2 颜色与尺寸必须用 token（必须）

**禁止在 `.bq-*` 之外新写色值**。所有颜色、圆角、阴影、间距引用全局 token：

```css
/* ❌ 禁止 */
.my-card { background: #5a7d5c; border-radius: 8px; padding: 10px; }

/* ✅ 正确 */
.my-card {
  background: var(--color-surface);
  border: 1px solid var(--color-border);
  border-radius: var(--radius-card);
  padding: var(--spacing-md);
}
```

`css/globals.css` 已定义 238 个自定义属性、引用 `var(--token)` 达 2008 次。

**JS 模板里禁止写 `style="..."`**（必须）—— 一律用 `.bq-*` 类。
详见 §6.2。

### 4.3 禁止的视觉手法（必须，由 CI 强制）

`scripts/audit-design.js` 是硬门禁，下列情形会**直接失败**：

| 项目 | 预算 | 说明 |
|---|---|---|
| 彩色 emoji 当图标 | **0 处** | 用 `BQ_ICONS` 线性图标（`js/core/utils.js`） |
| `backdrop-filter` | ≤ 3 处 | 玻璃拟态已全站下线 |
| 渐变 `linear/radial-gradient` | ≤ 4 处 | 装饰性渐变已清理 |

另有两个**棘轮**（只许下降、不得上调）：
- js 内联 `style="` 数量（当前基线见脚本内 `BASELINE_INLINE_STYLE`）
- js 硬编码唯一色值数（`BASELINE_UNIQUE_HEX`）

下调基线用 `npm run audit:design -- --update`（该命令在有其他失败项时拒绝执行，
这是防作弊设计，不要绕过）。

**动效预算**：只保留语义动效（加载 spinner / 骨架屏 / 输入指示 / 进度条 / 模态与toast 进出）。
禁止装饰型常驻动画（脉冲、发光、呼吸、漂浮）与 `hover` 位移。

### 4.4 玻璃拟态与渐变（必须）

- 卡片/弹窗/导航一律**实色面 + 1px 边框 + 单档中性阴影**
- 不用 `backdrop-filter`、不用 `saturate()`/`brightness()` 玻璃魔法
- 阴影走 `--shadow-sm/md/lg`，不要自定义大范围光晕

### 4.5 主样式表与 bundle（必须）

`css/bundle-core.css` 是**构建产物**，由
`node scripts/build-css-bundle.js` 从下列源文件生成：

```
globals.css → layout.css → header.css → learning-hub.css → home.css → debug-fix.css
```

**改样式必须改源文件，然后重新生成 bundle：**

```bash
# 改 css/globals.css后：
npm run build:css
```

审计脚本会校验 bundle 与源文件一致性（backdrop-filter / 渐变差值须为 0）。
**直接改 `bundle-core.css` 会被 CI 拦下。**

## 5. 目录与文件组织

### 5.1 js/ 分层

| 目录 | 职责 | 加载方式 |
|---|---|---|
| `js/core/` | 全局共享基建（app、utils、路由、主题、存储） | `<script defer>` 或首屏同步 |
| `js/pages/` | 页面级模块，一页一文件 | `window.loadModule()` 懒加载 |
| `js/ai/` | AI 相关引擎 | 按需懒加载 |
| `js/admin/` | 管理后台 | 按需懒加载 |
| `js/integrations/` | 第三方集成 | 按需 |
| `js/engagement/` | 社区/成就/习惯等激励 | 按需 |
| `js/vendor/` | **第三方原样文件，禁止手改** | 见 vendor 完整性门禁 |

### 5.2 新增页面模块

1. 文件放 `js/pages/<name>.js`
2. 在 `js/core/app.js` 的 `_moduleDir()`（若非 `pages/` 默认）和 `modNameToInitFn()` 注册
3. 导出 `init<Name>()` 作为初始化入口
4. 需要独立加载时，在 `index.html` 加 `<script defer>`

### 5.3 新增测试

- 单元测试：`tests/unit/<name>.test.js`（Jest，`testEnvironment` 默认 `node`，
  需 DOM 时在文件头加 `@jest-environment jsdom`）
- 测试加载业务 JS 的两种方式：
  ```js
  const SRC = fs.readFileSync(path.join(ROOT, 'js/core/utils.js'), 'utf8');
  (0, eval)(SRC);          // 全局脚本语义，与 index.html 一致
  ```
  或 `require()`（仅限 CommonJS 模块）

## 6. 设计系统与前端约定

### 6.1 全局组件类（`.bq-*`）

`css/globals.css` 末尾集中定义了全局设计系统，新增 UI **一律复用**，不要另起炉灶：

| 类 | 用途 |
|---|---|
| `.bq-btn` + `--primary/--ghost/--warm/--danger/--block/--sm` | 按钮 |
| `.bq-card` + `--flat/--sunken` | 卡片 |
| `.bq-chip` | 标签胶囊 |
| `.bq-section-header` | 区块标题（`__title`/`__desc`） |
| `.bq-dot` + `--high/--medium/--low/--none` | 状态点 |
| `.bq-result-icon` | 结果页图标 |
| `.bq-note` + `--warning/--danger` | 提示条 |
| `.bq-empty` / `.bq-empty-block` / `.bq-empty-note` | 空状态 |
| `.bq-input` | 输入框 |
| `.bq-center-vh` | 垂直居中容器 |
| `.bq-hint` + `--block/--block-sm/--xs/--mt/--amber/--success` | 辅助文字 |
| `.bq-m-*` / `.bq-mt-*` / `.bq-mb-*` / `.bq-fs-*` | 间距与字号工具类 |

### 6.2 内联样式收敛（必须）

**JS 模板中禁止 `style="..."`。** 高频写法已抽为类（见上表）。

抽类的判断标准（避免制造一次性类名）：
- **≥3 处**且语义相同 → 抽类
- 只出现 1~2 处 → 保留内联，**不要**为它建类

> 依据：实测 418 处内联样式去重后有 352 种写法，其中 **314 种只出现 1 次**。
> 强行全量抽类会产生 300+ 个一次性类名，维护成本高于收益。

### 6.3 图标（必须）

- 统一用 `js/core/utils.js` 的 `BQ_ICONS`：24 viewBox、stroke 1.8、`currentColor`
- **禁止用彩色 emoji 当图标**（CI 硬门禁，0 处预算）
- 图标颜色只靠 `color` 控制，不在图标上写 `fill`
- `✓` / `✗` 等排版符号不算图标，可用于状态标记

### 6.4 动画

- 只用 `transform` / `opacity` / `box-shadow` 做过渡（GPU 合成层）
- 缓动用平滑曲线，避免 `linear` 用于非加载动画
- 尊重 `prefers-reduced-motion`（开机遮罩已有示例）

## 7. 文案规范（必须）

**界面文案不得有AI 腔。** 「去 AI 味」是本项目的一贯要求，
`audit-design.js` 会检查部分项，但文案主要靠 review 把关。

| 禁止 | 说明 | 改为 |
|---|---|---|
| 情绪化评价 | 太厉害了、继续保持、恭喜、加油 | 给事实：`72 道题全部答对，满分。` |
| 空泛承诺 | 开启…之旅、一键、智能推荐、赋能、打造 | 给具体信息 |
| 营销自夸 | 极致、卓越、无缝、丝滑、最强 | 平实描述 |
| 拟人客套三连 | 「欢迎回来/欢迎来到/很高兴」到处重复 | 按场景用一次即可 |
| 「该X还是该Y」两难句 | AI 腔标志 | 直接陈述 |
| 装饰性 emoji | 🏆✨ 等 | 用 `BQ_ICONS` |

**原则：给事实，不给评价。**

> 例外：成就体系（`supabase-client.js` 的 `ACHIEVEMENTS`）是**刻意保留的俏皮文风**，
> 属项目性格，不在去 AI 味范围内。

## 10. 日志与待办（L-03）

### 10.1 统一日志（必须）

业务代码统一通过 `js/core/logger.js` 暴露的 `window.BQLog` 输出日志，不要直接调用
`console.log/info`：

```js
var log = (window.BQLog && window.BQLog.scope)
  ? window.BQLog.scope('Practice')
  : console;                     // logger 未加载时退回 console，保证模块可独立运行
log.info('练习数据已加载');       // 生产环境默认静默（级别 warn）
log.warnOnce('bank-missing', '题库分片缺失');  // 同一 key 只告警一次，避免轮询刷屏
```

- 默认级别：`localhost / 127.0.0.1 / file:` → `debug`；线上 → `warn`。
- 临时排查：URL 加 `?debug=1`，或执行
  `localStorage.setItem('tatabox_log_level','debug')` 后刷新。
- **禁止** monkey-patch / 覆盖全局 `console` 方法（会破坏浏览器调试工具与第三方库行为）。
- 用户可见的错误提示不要拼接原始异常文本；技术细节写日志，界面给可操作提示。

### 10.2 TODO / FIXME（应该）

- 代码中不长期保留无主 TODO/FIXME；确需延期的事项，转成 GitHub Issue 并在提交信息里引用编号。
