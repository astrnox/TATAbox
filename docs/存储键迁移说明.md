# 存储键品牌迁移说明（M-12）

## 背景

站点早期品牌为 BioQuest，Web Storage 键统一使用 `bioquest_*` 前缀。品牌更名为 TATABOX 后，
新数据改用 `tatabox_*`，同时必须保证老用户本地数据（设置、错题本、FSRS 进度、会话等）不丢失。

## 迁移机制

在 `js/core/utils.js` 顶部执行一次幂等迁移（先于所有业务模块加载）：

- 遍历 `localStorage` 与 `sessionStorage`；
- 把每个 `bioquest_*` 键的值复制到对应的 `tatabox_*` 键；
- **目标键已存在时不覆盖**（避免旧数据回灌）；
- **保留旧键**：未刷新的旧标签页 / 旧版离线页面仍可读写，避免数据凭空消失；
- 存储不可用（隐私模式、配额受限）时静默跳过，不阻断启动。

新代码一律只读写 `tatabox_*`。清理本地数据时会同时清除新旧两种前缀。

## 保持不变的旧标识（兼容契约）

以下标识**不是**普通缓存键，改名会破坏线上数据或既有用户，因此保持不变：

| 标识 | 位置 | 原因 |
|---|---|---|
| `@bioquest.local` | 用户名占位邮箱（前端 + SQL 登录 RPC） | 历史账号的真实 `auth.users.email`，改名会导致无法登录 |
| `bioquest_backup_key` | `js/core/storage.js` KDF 盐值 | 改名会使已导出的加密备份无法解密 |
| `bioquest_full_backup` | 备份/导入导出类型标识 | 改名会破坏旧备份文件的导入 |
| `bioquest-*` Cache Storage / IndexedDB 库名 | Service Worker / Dexie | 内部资源标识，不直接暴露给用户；保留可复用已有缓存 |

## 覆盖范围

- 共迁移 115 个键/前缀，涵盖：设置与主题、练习/考试记录、错题本、FSRS 卡、积分与成就、
  社区与通知、AI Key 会话、离线题库状态、管理端本地编辑等；
- 键名清单可通过以下命令复核（排除 node_modules / vendor）：

```bash
grep -rn "'tatabox_" js | sed "s/.*'tatabox_/tatabox_/" | sort -u
```

## 清理与回滚

- 过渡期内保留 `bioquest_*` 旧键；至少保留一个发布周期，确认无旧页面写入后再清理；
- 回滚只需回退代码版本：旧代码仍能读到未被删除的旧键；
- 用户主动「清除本地数据」时，新旧前缀会一并删除（见 `clearAllLocalData()`）。
