# 内容来源与授权清单（L-05）

> 用途：把仓库内**非代码内容**的来源、授权状态与处置建议集中登记，避免"源码开源 = 内容也可随意再分发"的误解。
> 代码授权见 [`LICENSE`](../LICENSE)（MPL-2.0）；内容授权见 [`LICENSE-CONTENT`](../LICENSE-CONTENT)（CC BY-NC-SA 4.0）。
> 本清单不构成法律意见；涉及商业使用或权利人异议时，以权利人的正式答复为准。

## 1. 授权分层

| 范围 | 授权 | 说明 |
|---|---|---|
| `js/`、`css/`、`scripts/`、`*.html` 等代码 | MPL-2.0 | 文件级弱 copyleft，可商用，修改文件须继续以 MPL-2.0 开源 |
| 项目原创题库、卡片、百科整理文本、动画说明文字等 | CC BY-NC-SA 4.0 | 非商业 + 署名 + 相同方式共享 |
| 第三方开源库（`js/vendor/`） | 各自许可证（MIT / Apache-2.0 / BSD / OFL 等） | 完整声明见 [`js/vendor/THIRD_PARTY_LICENSES.txt`](../js/vendor/THIRD_PARTY_LICENSES.txt) |
| **外部真题原卷 / 原卷题图 / 教材 PDF** | **不属于项目可再授权范围** | 版权归原发布方；仅限学习参考，见下文逐项说明 |

> 关键原则：CC BY-NC-SA 4.0 只覆盖**项目有权许可的原创内容**；对第三方试题、原卷图片、PDF 教材，本项目不主张版权，也不能用 CC 协议再授权。

|---|---|

## 5. 复核与纠错

- 权利人如认为站内内容侵权，可通过 GitHub Issues 联系，项目将在核实后下架相关内容。
- 新增内容 PR 检查项：
  - [ ] 来源链接或文献 DOI 已登记
  - [ ] 授权类型明确（原创 / CC / 公共领域 / 已获许可）
  - [ ] 非原创内容未套用 CC BY-NC-SA 再授权
  - [ ] 题图/视频封面含 `credit` 与 `license`
- 复核周期：建议每半年或在收到异议后立即复核一次。
