# 动画栏目移植技术方案 v2.0 —— 生物动画（Canvas）→ 生物动画视频栏目（含苛刻自审修订）

> **一句话目标**：删除主站现有「生物过程动画」Canvas 模块（`js/pages/bio-animation.js`），在同一栏目位置移植实现一个新的**视频播放栏目**，只上架版权干净的生物机制视频（如 CTL 识别 MHC-I、有丝分裂等）。
>
> **适用范围**：TATAbox（BioQuest）主站，原生 JS + 静态页面架构，无框架。
> **定位约定**：`文件:行号` 来自当前分支快照，实施时**以符号名 grep 定位为准**，行号仅作快速索引（§附录 C 给出可直接复制的自检命令）。
> **v2.0 变更**：新增第 0 章苛刻自审（17 项问题 + 修订），并据此修订 D1 决策、阶段步骤、验收标准与回滚流程。v1.0 中未经证据核实的表述已全部修正或标注。

### 1.4 视频素材版权准入标准（升级为 CI 硬门禁）

**允许**：① 公有领域（NIH/NIGMS、Wikimedia PD）；② CC BY / CC BY-SA（必须署名展示）；③ 免署名免费授权（Mixkit/Pexels/Pixabay，存授权页 URL 存证）；④ 教育机构明示允许再分发的资源（逐条核对 license 页）。
**禁止**：视频平台直接下载未授权内容；无授权标注、无法溯源的素材；未购商用授权的付费样片。

**入库必填五要素**（`data/videos.json`）：`license`（必须落在白名单枚举内）/ `source` / `attribution` / `poster` / `steps`。

**两道防线（v2.0 变化）**：
1. **CI 防线（新增，不可绕过）**：`scripts/verify-video-license.js` 校验——五要素齐全、`license` ∈ 白名单枚举、`file`/`poster` 实体存在、单文件 ≤ 阶段 -1 确认的限额。任一不满足 → exit 1 阻断合并。
2. **前端防线（兜底）**：`bio-video.js` 渲染前过滤缺失授权信息的条目。

骨架（相对 v1.0 修正两处：P0-4 的 esc、骨架注释强化版权门禁）：

```js
/**
 * TATABox — 生物动画视频栏目
 * 数据源：data/videos.json（唯一真源）
 * 双防线：本模块渲染过滤（兜底）+ scripts/verify-video-license.js（CI 硬门禁）
 */
(function() {
  'use strict';

  var _state = { list: [] };

  /* 模块内本地转义（依据 P0-4：utils.js 未导出 window.esc，参照 practice.js 写法） */
  function esc(s) {
    return String(s == null ? '' : s)
      .replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;')
      .replace(/"/g, '&quot;').replace(/'/g, '&#39;');
  }

  async function _loadVideos() {
    if (_state.list.length) return _state.list;
    try {
      var r = await fetch('data/videos.json');
      var j = await r.json();
      _state.list = (j.videos || []).filter(function (v) {
        return v && v.file && v.poster && v.license && v.source; // 兜底防线
      });
    } catch (e) { _state.list = []; }
    return _state.list;
  }

  /* _renderList / _renderPlayer：卡片网格与播放页
     <video controls playsinline preload="metadata" poster>
     署名行展示 attribution；有 VTT 时挂 <track kind="subtitles">（P2-2）
     播放前显示体积/Wi-Fi 提示（P2-1） */

  async function initBioVideo(target) {
    var list = await _loadVideos();
    if (!list.length) { target.innerHTML = '<div class="bv-empty">视频整理中，敬请期待</div>'; return; }
    /* ... */
  }
  function renderBioVideoPage(target) { initBioVideo(target); }
  window.initBioVideo = initBioVideo;
  window.renderBioVideoPage = renderBioVideoPage;
})();
```

**样式**：新建 `css/bio-video.css`（全部走 tokens 令牌、无 emoji、无渐变、无 backdrop-filter、零新增内联 style）。**若决定进 bundle：必须同时改 `build-css-bundle.js:SYNC_CSS` 和 `audit-design.js:BUNDLE_SOURCES` 两份清单（P0-1，缺一即错）**；不进 bundle 则由模块按需同源 `<link>` 加载，此时两清单都不动（二选一，**推荐前者**并双改）。
> **阶段 1 执行记录（2026-10-17）**：实际采用**不进 bundle** 的第二条路径，但加载方式用仓库既有的栏目样式惯例——`index.html` 中 `<link rel="preload" as="style" data-css-async>` + `<noscript><link>` 成对引入（practice/phet-sims/cards 等全部栏目 css 均如此），由 `boot-lazy.js` 在 DOMContentLoaded 前提升为生效样式表。理由：bundle-core 是 Issue #108 的**首屏同步**包，塞入非首屏栏目样式会反噬首屏（与 R8 相悖）；该路径下 `SYNC_CSS` 与 `BUNDLE_SOURCES` **均不改动**，P0-1 的双清单错位风险天然不存在（audit 棘轮实测未上升）。**变量体系修正（2026-10-17）**：初版误按 `css/tokens.css` 的 `--space-*`/`--step-*`/`--accent` 系列书写，但实测发现**主站 index.html 不加载 tokens.css（仅 lite.html 加载）**，全部变量落空导致 `bottom: var(--space-3)` 等声明失效、播放标记/时长角标错位、缩略图被图片固有高度撑破 16:9。已重写为 `css/globals.css` 主站语义令牌（`--color-sage`/`--text-*`/`--surface-*`/`--spacing-*`/`--font-size-*`，同 phet-sims.css 惯例带 fallback），并给 `.bv-thumb` 加 `overflow:hidden; min-height:0` 防 flex 子项自动最小尺寸撑高；Playwright 实测三卡统一 276×155（16:9）、角标与播放标记均在缩略图内。

**回滚后必做（三步缺一不可）**：

3. `git diff sw.js` 确认 CACHE_VERSION 再次变化（回滚最常见的失败原因就是用户拿不到回滚版）
